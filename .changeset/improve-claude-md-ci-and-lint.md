Harden `improve-claude-md` with what its 2026-11-18 run across two real repos found. The audit gains two problem rows: a Required workflows entry naming a skill that is not installed (14 across the two repos), and a blocking gate that nothing runs. The CI/CD standard now also applies when a gate table has no workflow (both repos had none, which the old "has a CI pipeline" condition marked not applicable) and gains gate parity, trunk baseline, what-CI-does-not-cover and who-can-enforce items. The agent-rules deny skeleton switches to live-tested wildcard forms, adds the `git -C *` variants (the first version let `git -C <path> reset --hard` through), and adds a pre-authorized-run item stated as its four parts. The write step now requires replaying every deny rule and hook against the command it is meant to stop, and running gate commands from a clean checkout, where three tests that read a gitignored directory, a locally installed binary and an uncopied script duly failed. Coding style gains a companion hook script, `lint-new-violations.py`, that reports only the violations an edit adds over HEAD, so a repo's lint debt never blocks a new edit.
