# 杂项（Misc）

我留着但很少用的工具，不在 plugin 中推广。

- **[git-guardrails-claude-code](./git-guardrails-claude-code/SKILL.md)**：设置 Claude Code hook，在危险的 git 命令（push、reset --hard、clean 等）执行前将其拦截。
- **[migrate-to-shoehorn](./migrate-to-shoehorn/SKILL.md)**：把测试文件中的 `as` 类型断言迁移为 @total-typescript/shoehorn。
- **[scaffold-exercises](./scaffold-exercises/SKILL.md)**：创建练习目录结构，包含章节、题目、答案和讲解。
- **[setup-pre-commit](./setup-pre-commit/SKILL.md)**：配置 Husky pre-commit hook，集成 lint-staged、Prettier、类型检查和测试。
