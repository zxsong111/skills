# 国际化 / 本地化

**适用条件：** 有多语言 UI 或服务多个地区的用户

**先探查：** i18n 库、文案资源文件放在哪、现有的硬编码字符串

## 待定项

逐项拍板；本项目不需要的写「不适用」。每项都写成可检查的句子。

| 项 | 要定什么 | 例子 |
|---|---|---|
| 文案外置 | UI 文案放进资源文件；绝不硬编码 | 无 |
| Key 命名 | 按页面 / 模块分层 | `checkout.button.pay` |
| 格式化 | 数字、日期和货币使用感知 locale 的 API | `Intl.NumberFormat` |
| 新增语言 | 缺失翻译时的回退策略 | 回退到 en |

## 落点

- 第 2 层：硬编码字符串检测（eslint-plugin-i18next 之类）
- 第 3 层：`.claude/rules/i18n.md`，`paths:` 限定在 UI 目录
