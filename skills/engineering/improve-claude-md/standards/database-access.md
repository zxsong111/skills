# 数据库访问

**适用条件：** 读写数据库的服务

**先探查：** ORM / 查询风格、事务的写法、慢查询日志

## 待定项

逐项拍板；本项目不需要的写「不适用」。每项都写成可检查的句子。

| 项 | 要定什么 | 例子 |
|---|---|---|
| N+1 | 列表查询必须预加载关联；绝不在循环里查数据库 | 无 |
| 事务 | 事务边界放在 service 层；事务内不做外部调用 | 无 |
| 查询 | 参数化；绝不用字符串拼接 SQL | 无 |
| 索引 | 每新增一个查询条件都评估是否需要索引 | 无 |
| 读写分离 | 哪些查询可以走只读副本 | 无 |
