# Triage Labels

这些 skill 用五个规范的分诊角色(triage role)来表述。本文件把这些角色映射到本 repo 的 issue tracker 中实际使用的标签字符串。

| Label in mattpocock/skills | Label in our tracker | 含义                              |
| -------------------------- | -------------------- | --------------------------------- |
| `needs-triage`             | `needs-triage`       | 需要维护者评估这个 issue          |
| `needs-info`               | `needs-info`         | 等待报告者提供更多信息            |
| `ready-for-agent`          | `ready-for-agent`    | 已完全明确，可以交给 AFK agent    |
| `ready-for-human`          | `ready-for-human`    | 需要人来实现                      |
| `wontfix`                  | `wontfix`            | 不会处理                          |

当某个 skill 提到一个角色时（例如「打上 AFK-ready 分诊标签」），使用此表中对应的标签字符串。

修改 "Label in our tracker" 这一列，让它与你实际使用的词汇一致。
